# Expense Flow

A full-stack expense management application built using Spring Boot, React, JWT Authentication, and MySQL.

## Features

- User Registration & Login
- JWT Authentication
- Expense CRUD Operations
- Category Filters
- Date Range Filters
- Amount Range Filters
- Search Expenses
- Pagination
- Dashboard Summary
- Expense Analytics Chart
- Responsive Dark Theme UI

## Tech Stack

### Backend
- Java 21
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA
- Hibernate
- MySQL

### Frontend
- React
- React Router
- Axios
- Recharts
- React Toastify

## Run Backend

```bash
cd backend
./gradlew bootRun
```

## Run Frontend

```bash
cd frontend
npm install
npm run dev
```
